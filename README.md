# Passat B6 EcoFuel — интерактивный мануал

Автономный HTML-справочник по **VW Passat B6 1.4 TSI EcoFuel** (мотор CDGA,
110 кВт, бивалентный метан/бензин, DSG-7 DQ200 `0AM`) и Android-приложение
вокруг него.

Это выжимка из личного диагностического проекта: нормы каналов, порядок замеров
и разборы по системам, собранные при ремонте конкретной машины. Персональные
данные автомобиля сюда не входят.

## Что в мануале

55 карточек с поиском, фильтром по разделам и чек-листом, который сохраняет
отметки в браузере:

- **Каналы** — измеряемые группы блока 01 с нормами: газовая часть (187, 241,
  245, 188), бензиновая рампа, пропуски, лямбда-зонды, фаза распредвала,
  наддув, поиск подсосов воздуха, комплексный проход по мотору.
- **Коды** — разбор конкретных ошибок со стоп-кадрами и привязкой к бюллетеням VW.
- **Процедуры** — форсунки, редуктор, свечи под метан, картерные газы, свист
  ремня, стойки стабилизатора, навигация по диагностической программе,
  логины к закрытым областям.
- **DSG** — проверка сцеплений DQ200 по заводским нормам.
- **Электрика** — Climatronic, кондиционер по контуру, PTC-подогреватель (блок
  7D), подогрев форсунок омывателя, предохранители, стояночный тормоз.

Данные из заводских источников (SSP 425, бюллетени TPI, процедуры ELSA, файлы
меток диагностической программы) отмечены как таковые; найденное на форумах
помечено звёздочкой и отделено от заводских норм.

## Как пользоваться

**На компьютере:** открыть `docs/МАНУАЛ.html` в браузере, интернет не нужен.

**На Android:** скачать `Passat-EcoFuel-Manual.apk` и установить (понадобится
разрешение на установку из неизвестных источников).

**На iPhone:** положить `docs/МАНУАЛ.html` в «Файлы» через AirDrop или iCloud
Drive и открывать оттуда.

Ссылки на документы библиотеки в тексте оставлены как пути — сами документы
принадлежат VW AG и в этот репозиторий не входят.

## Сборка APK

```bash
cd android-app && ./gradlew assembleDebug
```

Либо через GitHub Actions — воркфлоу `Build Android APK` в этом репозитории.
